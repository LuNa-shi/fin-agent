# Security policy

## Supported versions

Fin Agent is currently maintained on the default branch. Because the project is under active development, security fixes are expected to target the latest version of the default branch.

## Reporting a vulnerability

Please do not report credentials, provider endpoints, raw provider payloads, or exploitable details in a public issue.

Use GitHub's private vulnerability reporting feature for this repository when it is enabled. If private reporting is unavailable, open a minimal public issue asking the maintainers for a private reporting channel and do not include sensitive details.

Please include enough information for the maintainers to reproduce the issue safely:

- affected commit or version;
- affected component or route;
- reproducible steps using synthetic data;
- expected and observed behavior;
- impact assessment;
- a suggested mitigation, if known.

Do not attach real credentials, user data, private reports, or raw provider responses. Use redacted examples and isolated temporary data roots.

Maintainers will acknowledge reports, investigate them, and coordinate a fix and disclosure timeline based on severity and impact.
